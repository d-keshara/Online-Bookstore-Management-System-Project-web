# 📚 Online Bookstore Management System

## 📌 Project Overview
This project is a web-based Online Bookstore Management System developed using Spring Boot and MySQL. It allows users to browse books, manage accounts, place orders, and leave reviews.

---

## 🛠️ Technologies Used
- Java (Spring Boot)
- MySQL
- HTML, CSS, JavaScript
- GitHub (Version Control)

## ⚙️ Features
- User Registration & Login
- Book Management (Add, Update, Delete)

- Review System

## 📁 File Handling

## 🚀 How to Run the Project

1. Clone the repository
2. Open in IDE (IntelliJ / Eclipse)
3. Configure MySQL database
4. Run Spring Boot application
5. Open browser and access the system
